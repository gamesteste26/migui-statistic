# MIGUI STATISTIC

Aplicativo Android nativo em Kotlin + Jetpack Compose.

## Build
Execute `gradle assembleDebug` para gerar:
`app/build/outputs/apk/debug/app-debug.apk`

O workflow do GitHub Actions compila o APK a cada push na branch `main` e publica o arquivo como artefato.

## Estado atual
Primeira estrutura visual do aplicativo. Os dados esportivos ainda não estão conectados; a interface não exibe estatísticas fictícias.
